# Solangge Naranjo — Currículum Vitae Profesional

Sitio web minimalista, elegante y de alto impacto para el perfil profesional de **Solangge Naranjo** (Licenciada en Ciencia y Cultura de la Alimentación, Supervisora de Producción y Calidad en Agroindustria & Retail).

Desarrollado con **Next.js (App Router)** y **Tailwind CSS**.

---

## 🚀 Características

- **Diseño Editorial Minimalista:** Enfoque tipográfico premium utilizando Google Fonts (**Lora** para títulos y **Inter** para lectura).
- **Paleta de Colores Curada:** Fondo marfil suave (`#FAFAF9`), texto carbón (`#27272A`) y detalles/acentos en verde salvia (`#3F6242`).
- **Descarga de PDF Directa:** Opción para descargar la versión en PDF del CV con un clic.
- **Modo de Impresión Optimizado:** Soporte nativo para impresión y guardado como PDF desde el navegador con reglas CSS `@media print` que suprimen botones y evitan cortes de página inapropiados.
- **Contacto Directo:** Enlace directo a **WhatsApp** (`+58 416-5526627`), marcación telefónica, correo electrónico y perfil de **LinkedIn**.
- **100% Responsivo:** Adaptado fluidamente a dispositivos móviles, tablets y escritorios.
- **Optimizado para SEO:** Metadatos completos OpenGraph, semántica accesible y estructurada.

## 💻 Desarrollo Local

1. Clona el repositorio:
```bash
git clone https://github.com/Volodya-770/SolanggeNaranjoCV.git
cd SolanggeNaranjoCV
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

---

## 📦 Compilación para Producción

```bash
npm run build
npm run start
```
